# 윈도우 실행 파일 (더블클릭용)

터미널 명령을 몰라도 **파일을 더블클릭**하면 됩니다. 순서대로 하세요.

## 처음 한 번만

| 파일 | 하는 일 |
|------|---------|
| **설치.bat** | 이거 하나만 누르면 됩니다. 가상환경 + aist 설치 + 설정파일 준비 + 방송 코어 준비 + 점검 |
| **코어준비.bat** | 방송 코어만 따로 준비 (웹UI + 의존성 + `conf.yaml`) — 설치.bat 이 자동으로 부르지만, 실패했을 때 이걸로 다시 |
| **프론트엔드받기.bat** | 웹UI(화면)만 따로 받기 |

설치 후 메모장으로 아래 3개를 열어 채웁니다:
- `config.yaml` — 플랫폼, 방송 시간 등
- `persona.yaml` — 캐릭터(이름·말투). 바꾸면 코어에 다시 넣기:
  `aist build-persona --conf Open-LLM-VTuber\conf.yaml --live2d <모델명>`
- `.env` — 키/토큰(LLM, 디스코드, OBS 비번, 플랫폼 등)

## 매번 방송할 때

| 파일 | 하는 일 |
|------|---------|
| **코어실행.bat** | 방송 코어(Open-LLM-VTuber) 실행 — 목소리·아바타 |
| **점검.bat** | 필요한 패키지·웹UI 가 갖춰졌는지 + 코어/OBS/플랫폼 채팅이 잘 붙는지 확인 |
| **리허설.bat** | 플랫폼·키·OBS 없이 흐름만 확인 (가짜 채팅, 송출·공지 안 나감, 기록은 `data\rehearsal\` 에만) |
| **테스트방송.bat** | 지금 한 방송만 (시작 수동, 종료 자동) — 비공개 테스트용 |
| **방송시작.bat** | 완전 자동 운영 (스케줄러가 켜고 끔) |
| **전체실행.bat** | 코어 + AI 방송인을 한 번에 (클릭 하나로). 코어가 뜰 때까지 기다린 뒤 시작 |
| **중단.bat** | **도는 방송을 안전하게 내린다** — 마무리 인사 → OBS 스트림 종료 → 기록 저장 |
| **리포트.bat** | 직전 방송 리포트 + 컨텐츠 팩 보기 |

> ### 방송을 끌 때는 반드시 **중단.bat**
>
> 방송 창을 **X 로 닫지 마세요.** 윈도우가 프로그램을 바로 죽여서
> **OBS 스트림이 켜진 채 남습니다.** 시청자에게는 멈춘 화면이 계속 나갑니다.
>
> `Ctrl+C` 도 권하지 않습니다. cmd 가 "현재 배치 작업을 끝내시겠습니까 (Y/N)?"
> 를 먼저 묻는데, 거기서 `Y` 를 누르면 정리 중간에 끊길 수 있습니다.
>
> **중단.bat 을 다른 창에서 더블클릭**하면 방송인이 마무리 인사를 하고
> 스트림을 내린 뒤 기록까지 저장하고 끝냅니다. 사고가 났을 때도 이걸 쓰세요.

## 24시간 무인 운영

| 파일 | 하는 일 |
|------|---------|
| **자동시작등록.bat** | 로그인할 때마다 자동으로 켜지게 등록 (윈도우 작업 스케줄러) |
| **무인운영.bat** | 위가 등록하는 실체. 코어/방송인이 죽으면 10초 뒤 다시 띄움 (사람이 볼 땐 전체실행.bat) |
| **자동시작해제.bat** | 위 등록을 해제 |

> 컴퓨터가 꺼져 있거나 절전이면 방송도 안 됩니다. 무인 운영하려면
> **설정 - 시스템 - 전원** 에서 절전을 꺼두세요.

> **점검이 "지금 상태로는 방송이 안 됩니다" 라고 하면 진짜로 안 됩니다.**
> 거기 적힌 것부터 해결하세요. 그냥 방송시작.bat 을 눌러도 시작하자마자 멈춥니다.

> **OBS** 는 미리 켜두거나, `config.yaml` 의 `obs.launch_if_not_running` 을
> 설정하면 자동으로 켜집니다.

## exe 파일이 꼭 필요하면

| 파일 | 하는 일 |
|------|---------|
| **EXE만들기.bat** | `dist\aist.exe` 생성 (PyInstaller) |

> `.bat` 만으로도 다 됩니다. exe 는 우리 자동화 레이어일 뿐이라, exe 를
> 만들어도 방송 코어와 OBS 는 따로 실행돼 있어야 실제 방송이 됩니다.

## 24시간 무인 운영

창을 계속 띄워두는 대신, 서비스로 등록하면 꺼져도 자동 재시작됩니다.
윈도우는 **작업 스케줄러**에 `방송시작.bat` 을 "시작 시 실행 / 실패 시 재시작"
으로 등록하거나, 리눅스 서버면 `deploy/install.sh` 를 쓰세요.
(자세한 건 `docs/INTEGRATION.md`)
